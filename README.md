A tiny program with one job: it writes a single short text to /output/entry.txt — a thank-you addressed to the reader, for the invisible work of reading itself. Python 3 standard library only; the text is embedded in main.py, and the program is deterministic and uses no network.

## Run it

```sh
python3 main.py
```
